# Python ブロック練習 — 売上データ探偵（試験版）

[HTML ブロック練習](https://github.com/Badgio0906/html-block-practice) の「操作 → コードを見る → 結果を確かめる」を、Python ならではの**データ処理**に置き換えた試験版です。架空のカフェの注文 120 件を、天気で絞り込み、個数または売上でランキングにします。設定から Python コードが生成され、ブラウザ内の Python（Pyodide）が実際に実行します。コードを直接書き換えて実験することもできます。

## 試す

Python 3 がある環境で、このフォルダから次を実行し、表示されたアドレスを Chrome / Edge で開いてください。

```sh
python3 -m http.server 8000
```

最初の実行時だけ Pyodide を CDN から読み込むため、インターネット接続が必要です。CSV とコードはブラウザ内で処理し、アプリのサーバーには送信しません。`file://` での直接起動は Worker と CSV 読み込みに対応しないため、上のローカルサーバーか静的ホスティングで開いてください。

1. 「いちばん人気は？」を選んで実行します。
2. 「雨の日は？」を押して結果の違いを見ます。
3. 「売上で比べる」に変えると、数と金額では答えが変わることを確かめられます。
4. `sample.csv` と同じ `date,weather,item,price,quantity` の見出しを持つ UTF-8 CSV も読み込めます。`weather` は `rain` または `sun`、`price` と `quantity` は整数です。

## 試験版の範囲

- ブロックに相当する設定は「絞り込み」「集計」「表示件数」の 3 つです。
- 生成コードに、`csv.DictReader`、`for`、`if`、辞書による集計、並べ替えを含みます。
- 実行は Web Worker 内で行い、実行中のコードは 8 秒で中止できます。中止後は Worker を作り直して再実行できます。
- 自由編集したコードは結果文字列または `print()` の出力を表示できます。棒グラフは、生成コードと同じ形の JSON を最後に返した場合に表示します。
- 学習進捗、正誤判定、タイピング課題はこの試験版には未搭載です。体験の手応えを確かめてから教材化します。
