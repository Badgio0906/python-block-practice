上部の切り替えでHTML版とPython版を行き来できます。Python版は、初めて触る人が「こんなこともできるんだ」と感じられる4つの体験教材です。**このブランチの新教材は公開サイトにはまだ反映していません。**

## 教材の一覧

| 教材 | やってみること | 学ぶ要素 |
| --- | --- | --- |
| 売上データ探偵 | カフェの注文120件から人気商品を見つけ、雨の日や売上金額でも比べる | `for`、`if`、CSV、辞書 |

Pythonのホーム画面から4教材を選べます。各教材には3つのミッション、段階的なヒント、編集できるPythonコード、実行結果、初期化があります。ミッションは操作とPythonの結果を確かめて達成になり、進捗だけをブラウザの`localStorage`に保存します。達成後も自由に試せます。

## 起動方法

Python 3でリポジトリのルートから実行します。

```sh
python3 -m http.server 8000
```

ChromeまたはEdgeで `http://127.0.0.1:8000/` を開いてください。バックエンドやAPIキーは不要です。ファイルを直接ダブルクリックする`file://`起動は、WorkerやCSVの読み込みに対応しません。

初回はPyodide 0.27.7をCDNから読み込むためインターネット接続が必要です。読み込み後のPython計算はWeb Worker内で行い、チャットやCSVの内容をアプリのサーバーへ送信しません。CDNがキャッシュされていないオフライン環境ではPythonを実行できません。

PC版Chrome / Edge相当とスマートフォン幅のChromiumで検証しています。Safariなどは未検証です。

## よくあるエラー

- **Pythonが読み込めない**：通信を確認し、再読み込みしてください。初回ロードには時間がかかります。
- **ガチャを引けない**：3つの確率が0〜100の整数で、合計100%か確認してください。名前も3つ必要です。
- **ロボットが返事をしない**：空のメッセージは送信できません。追加したルールに言葉と返事が入っているか確認してください。
- **アートが描けない**：線の長さ10〜180、角度1〜179、回数1〜150の範囲にしてください。
- **コードを直したい**：「コードを戻す」で現在の設定から再生成できます。設定を変えると手で編集したコードは消えます。
- **止まらないコードを書いた**：「停止」でWorkerを終了します。その後、再実行できます。
- **CSVを読めない**：UTF-8で`date,weather,item,price,quantity`の列を用意し、1 MB以内にしてください。

## 検証

```sh
npm test
npm run test:browser
```

`npm test`はNode.jsとPython 3を使用します。ブラウザ検証にはPlaywrightパッケージとChromiumが必要です。テスト環境では `/usr/bin/chromium` を使用し、別の場所にある場合は`CHROMIUM_PATH`で指定できます。通常の教材利用にnpmパッケージは不要です。GitHub Actionsのワークフローは追加していません。

詳細な構成と教材の追加方法は[ARCHITECTURE.md](ARCHITECTURE.md)を参照してください。
