# Python ブロック練習

HTMLブロック練習の「ブロックを並べる → コードを見える化する → 実行して確かめる → 理解を確認する」という学習体験を、Python向けに再設計するプロジェクトです。

## 目標

Webサイトの制作ではなく、Pythonの基礎を理解し、自分で小さな処理や道具を設計・実装できるようになることを目的とします。

- ブロック組み立てからタイピング、自由記述へ段階的に移行
- 実際のPythonをブラウザで実行（Pyodideを候補とする）
- コード、出力、エラー理由の対応を分かりやすく表示
- 日本語の課題、ヒント、振り返り
- 進捗のローカル保存と教材・コードのエクスポート

## カリキュラム案

1. 出力と値：`print`、文字列、数値、変数
2. 条件分岐：比較演算子、`if` / `elif` / `else`
3. 繰り返し：`for`、`range`、`while`
4. データ：リスト、辞書、スライス
5. 関数：`def`、引数、戻り値
6. エラー対処：例外、デバッグ
7. 実践：文字列処理、CSV、ファイル入出力（ブラウザ内の仮想ファイル／ユーザーが許可したファイルに限定）
8. 卒業課題：データ集計または日常の小さな自動化を設計する

## 方式

- UI: HTML / CSS / JavaScript（フレームワークは要件確定後に検討）
- Python 実行: Pyodide + 専用 Web Worker を第一候補とし、先に短い技術検証を行う
- 配信: 静的ホスティング（GitHub Pages を想定）
- 保存: 進捗はブラウザローカル。外部サーバー・ログインは当初不要
- 初回のPython実行環境ロードには通信が必要

**注意**: Pyodideは万能なOSレベルのサンドボックスではありません。任意Python実行の安全性、停止・再起動、メモリ使用量、出力サイズなどを確認すること。Pythonのファイル・ネットワーク操作の一部はブラウザの制約を受けます。

## 最初の開発ゲート

- [ ] Pyodideが最新のChrome / Edge上で読み込める
- [ ] `print`, 分岐、ループ、関数、例外を実行し結果を表示できる
- [ ] `while True` を強制停止でき、ワーカー再生成後も再実行できる
- [ ] `input()` 相当の対話方法を設計・実測する
- [ ] 実行ごとに標準出力・例外を分離し、前回の状態の影響を制御する
- [ ] ブロック編集結果と表示コードに齟齬がない
- [ ] ステージクリア判定が単純な文字列一致に依存しない
- [ ] 誤操作や再読み込みで進捗が壊れない
- [ ] アクセシビリティ（キーボード操作・焦点移動・読みやすさ）を確認する

## 実装進行

1. 技術検証：実行エンジン、Worker停止、入力／出力、ブラウザ互換性
2. 最小教材：`print`・変数・`if`でブロック／コード／結果の一連を確認
3. ステージシステム：課題・ヒント・判定・進捗
4. 段階的タイピング・自由記述、カリキュラム拡張
5. 品質テスト・配信
